# Agent notes

This repo follows `docs/architecture.md`. Where that document and this file disagree, follow the architecture.

- Routes stay in `src/app/`. Business code stays in `src/features`, SQL stays in `src/db`, thin wrappers around native capabilities stay in `src/platform`, and pure React-free helpers stay in `src/lib`. Pages call features only.
- Only `src/db` may import `expo-sqlite`. Only `src/platform` may import other native modules (`expo-secure-store`, `expo-speech`, `expo-audio`, `expo-file-system`, `expo-document-picker`, `expo-sharing`, ...). ESLint enforces both.
- When you add a native dependency, add it to `PLATFORM_NATIVE_MODULES` in `eslint.config.js` in the same change. ESLint only blocks modules on that list, so an unlisted native module can be imported anywhere without warning. Display-only packages are the exception and may be imported directly from pages and `src/ui`: `expo-status-bar` and `@expo/vector-icons` (and the router itself, `expo-router`).
- The LLM API key is stored only with `src/platform/secure-store.ts` (`expo-secure-store`). Do not write it to SQLite, logs, or the bundle.
- v1 ships a local Android APK from `.github/workflows/release.yml`. Do not add EAS or any paid build service.
- `android/` and `ios/` are generated by `expo prebuild` and gitignored. Change native config through `app.config.ts` and config plugins.
- Before finishing a change, run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run e2e`.
