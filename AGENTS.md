# Agent notes

This repo follows `docs/architecture.md`. Where that document and this file disagree, follow the architecture.

- Routes stay in `app/`. Business code stays in `src/features`, SQL stays in `src/db`, and React-free helpers stay in `src/lib`.
- The LLM API key is stored only with `src/lib/secure-store.ts` (`expo-secure-store`). Do not write it to SQLite, logs, or the bundle.
- v1 ships a local Android APK from `.github/workflows/release.yml`. Do not add EAS or any paid build service.
- `android/` and `ios/` are generated by `expo prebuild` and gitignored. Change native config through `app.config.ts` and config plugins.
- Before finishing a change, run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run e2e`.
